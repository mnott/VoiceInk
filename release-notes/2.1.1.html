What's New in VoiceInk 2.1.1

Dictation can now be aimed at a destination you choose, instead of always landing wherever the cursor happens to be.

  • 📌 Pinned destination — Pin whatever you can type into with a shortcut, then keep dictating into it while you read and work somewhere else. Focus is never stolen. Works with an iTerm2 pane or a focused text field in any app.
  • 🎨 Tint the pinned pane — Give a pinned iTerm2 pane a background colour of your choosing, with adjustable opacity, so you can tell at a glance which one is pinned. The original colour is captured first and always restored. The menu bar icon uses the same colour.
  • ⚙️ Per-application delivery options — Decide per app what happens when dictated text arrives: switch the app into typing mode first, submit with Return afterwards, or leave a trailing space so you can keep dictating. These apply to ordinary dictation as well as to a pinned destination.
  • 🐛 Auto Enter now works with Custom Command modes — The "Auto Enter after transcription" setting was silently ignored whenever a Mode's output was a Custom Command, so the text arrived and was never submitted.
  • ⌨️ Global shortcuts no longer share the main thread — The keyboard event tap now runs on its own thread, so a busy app can no longer delay system-wide keyboard input.
