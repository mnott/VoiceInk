What's New in VoiceInk 2.2.1

Fixes for imported meeting recordings: correct audio decoding, visible errors, and your language choice respected.

  • 🎙️ Meeting WAVs from other apps decode correctly — Recordings converted with ffmpeg or written by other tools carry extra RIFF chunks before the audio data; VoiceInk assumed a fixed 44-byte header, which shifted and swapped the channels. The header is now parsed properly, so an imported meeting file transcribes with mic and system channels intact.
  • 🔍 Transcription failures are no longer silent — If a turn's transcription fails (e.g. the model is missing), the error is logged instead of being swallowed as empty text. An imported file that produces an empty transcript now tells you why.
  • 🇩🇪 Meeting re-transcription honours your language setting — Re-transcribing a meeting file used the raw language default (autodetect) instead of the language selected in your active mode, so short noisy passages could come out in the wrong language. The meeting path now uses exactly the same validated language as dictation.
